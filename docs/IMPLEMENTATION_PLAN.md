# Retention Studio implementation plan

Agreed scope, 12 October 2026. Offline independent Razorpay Agent Studio concept.

1. Fictional Nira Botanics skincare/haircare catalog with variants and bundle components.
2. Exactly 30,000 orders across six rolling monthly windows (12 April–11 October 2026), averaging 5,000 monthly; normalized CSV tables and SQLite generated from the app source.
3. Separate merchant observations, simulated Razorpay/Vulcan signals and retention estimates. Vulcan is a payments foundation model, not a text LLM. No live signal access.
4. Custom/recommended campaigns, WhatsApp/voice editors, email coming soon, drafts, reusable templates, versioned approval, scheduling, pausing, simulated execution and reconciled outcomes.
5. Daily opportunity refresh through a simulated clock; retain merchant edits and recheck eligibility before sends. Approved audiences and assets cannot silently expand or change.
6. Independent synthetic benchmark: organic, conventional, merchant-only and network-enriched strategies. Shared populations and hidden outcome assumptions, not proof of causal uplift.
7. Illustrative 25% share of aggregate incremental contribution. Operator bears communication/AI costs; refunds and collection determine settlement readiness. Losses offset gains before fees.
8. Verify joins, totals, consent, approval, persistence, workflow UI and build; push additive commits to connected main without rewriting history.

Live OAuth, signal retrieval, messaging/voice, generative bitmap creatives and invoicing remain documented integration boundaries. No real customers are contacted.
